# Русская локализация

Версия сборки: **1.0.2**.

Интерфейс проверки изменений не поддерживает бинарные файлы, поэтому русский
пакет хранится в переносимом текстовом виде:
`locales/ru-RU.pak.gz.b64`. Это gzip-сжатый PAK, закодированный в Base64.

## Создание `ru-RU.pak`

Из корня проекта выполните команду:

```bash
python tools/build_ru_locale.py
```

Она создаст готовый файл `locales/ru-RU.pak` и автоматически проверит его
SHA-256. Внешние библиотеки и доступ к интернету не требуются.

Контрольная сумма готового файла:

```text
bf805e332d92af376112d6f6720e416117073454f2d92ed89c4275a2347eb9c6
```

Поместите полученный `ru-RU.pak` рядом с `en-US.pak` в каталоге `locales`
приложения. Electron выбирает его при русской системной локали или при запуске
с параметром `--lang=ru-RU`.
